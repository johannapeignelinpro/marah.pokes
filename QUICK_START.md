# 🚀 Démarrage rapide - Marah.Pokes

## Étape 1 : Ajouter l'image de fond

**IMPORTANT** : Copiez le fichier `Template_Fond__1_.jpg` que vous avez fourni dans le dossier :

```
Marah.Pokes/public/assets/Template_Fond__1_.jpg
```

## Étape 2 : Lancer le serveur de développement

Ouvrez un terminal dans le dossier du projet et lancez :

```bash
cd Marah.Pokes
npm run dev
```

Le site sera accessible sur : **http://localhost:4321**

## Ce que vous allez voir

Le site comporte 4 sections principales :

1. **Hero** : Section d'accueil avec le nom et le slogan
2. **À propos** : Explication du handpoke + présentation de l'artiste
3. **Galerie** : Placeholder pour les photos de tatouages (à remplir)
4. **Contact** : Formulaire de contact (à configurer)
